# ReCo 数据集调研

本目录集中保存 ReCo 数据集的调研记录、人工审核表、阶段结论和后续辅助脚本，保持浅层结构。

当前只执行第一大步：熟悉数据集并观察数据质量。暂不转换训练样本、不选择基模、不进行微调，也不引入数据库。

## 文件

- `examples/`：已校验并解压的官方可视化示例。
- `examples.tar`：原始示例包已在解包和校验后删除；需要时按 `reco_pull_plan.md` 重新下载。
- `reco_notes.md`：数据集结构、来源和观察笔记。
- `reco_pull_plan.md`：小规模样本拉取和停止点。
- `reco_inventory.csv`：全部官方示例的文件、指令与视频技术信息。
- `reco_audit.csv`：逐条样本的人工审核记录。
- `reco_report.md`：完成抽查后的阶段结论。
- `prepare_examples.py`：重新生成 inventory 和首批审核表的脚本。
- 后续脚本直接放在本目录，不再增加多层脚本目录。

## 审核约定

- 通用抽查规则见根目录的 `DATASET_AUDIT_GUIDE.md`。
- `reco_inventory.csv` 是 204 条示例的总目录，`reco_audit.csv` 是其中 40 条的人工审核子集；两者使用 5 位 `hash` 短标签进行人工查找。
- 5 位哈希不要求全局唯一，发生碰撞也不额外处理。
- 审核表不重复保存文件路径或左右位置；使用 `hash` 即可在 `examples/` 中找到对应视频和指令。
- 新生成的审核记录默认全部标记为“通过”。
- 人工审核时只修改“存疑”或“不通过”的项目，并在 `notes` 中简要说明原因。
- `logical_correctness` 用于记录编辑后的物理或交互逻辑是否合理，例如人物被删除后，其动作造成的交互效果却仍然存在。
- `notes` 是自由文本字段，可以详细记录问题；CSV 写入脚本会正确处理其中的逗号和换行。
- `prepare_examples.py` 默认保留已有审核表，避免覆盖人工填写内容；只有显式使用 `--reset-audit` 才会重建审核表。
- 当前不建立 SQLite 数据库；需要引入数据库时先征求用户确认。
