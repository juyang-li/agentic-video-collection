# 师兄新版 DataMake 数据审核包

解压整个 ZIP 后打开 `index.html`。80 条编辑按 8 组排列，可以一直向下滚动，没有评分选项。视频旁有“打开文件”，参考图可点击原尺寸查看；播放按钮从头一起播放该条 source/target/ref video，逐视频也保留原生播放控件。

- 每组 10 条：身份、单件服装、整套服装、动作、场景、发型、发色、镜头。
- 64 条独立单轮 + 16 条多轮焦点编辑；多轮可展开完整历史、所有轮的 prompt 和参考。上下文不另计入 80 条。
- SOURCE 是真实图边输入，TARGET 是合成配对输出，不是本次模型推理结果。
- 所有 prompt 为原始中英文，无改写、无截断。引用顺序及服装/发型正背面对保留。无参考样本明确标注，未虚构 ref。
- 视频保留原始 1080p 横竖屏、30 FPS、300 帧、10 秒。部分为已完成的 CRF18 H.264 浏览副本，其余使用原始码流无损封装，均无声，未裁剪、降分辨率、变速或插帧。图片为原 PNG；逐文件处理方式见 manifest.json。
- 本包完整离线，无需联网；浏览器滚到附近才加载视频。展开多轮历史会增加媒体加载量。

`REPORT.md` 是本次数据结构、抽样和 prompt 风格报告。`manifest.json` 是焦点编辑与媒体映射，`inventory.csv` 便于查找文本，`provenance/` 保存原始样本、链和目录说明，`technical_validation.json` 和 `browser_validation.json` 记录本地技术验收范围。

抽样按任务均衡，不能代表原始任务占比。train/test 混合用于人工浏览；未来训练/评测仍须按来源分组隔离。来源只读，未改写师兄原始数据。本次动作仅用于合成数据审核，不加入之前的首轮推理 bench。
