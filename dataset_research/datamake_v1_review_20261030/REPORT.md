## Prompt 的主要风格

**双语、指令式、原子修改，参考语义和保持约束写得具体。** 常见开头是 Please change / Please replace / I'd like to…，而不是对目标视频的长篇镜头描述。主干通常为“改什么 → 参考只提供什么 → 什么保持不变”。各类有少量同义模板；具体颜色、动作、镜头及穿搭列表填入槽位。

单轮 31,702 条全部带统一前缀：

> Using the provided source video, apply the following edit:

中文对应“请基于输入视频进行以下编辑：”。这是编辑输入声明，不是历史选择。前缀后偶尔再次出现 Please/请，形成模板拼接感，但应原样保留供审核，不为提升观感改写原文。

| 英文不同完整文本 | 847 | 3,756 |
| 中文不同完整文本 | 861 | 3,786 |

## 各任务的条件边界

| 任务 | 典型表达和参考用途 | 明确保持或允许改变 |
| --- | --- | --- |
| 身份 | reference photo 提供 facial identity 和 skin tone | 肤色一致应用到脸和身体；不复制参考人物的发型、发色和表情 |
| 单件服装 | top / bottoms / one-piece garment 等替换为 reference images 中单件 | 其它衣物、鞋及非服装属性保持；每件附正背图 |
| 整套服装 | complete outfit，列出实际衣物/鞋/配件，强调完整穿搭 | 移除不属于目标搭配的旧衣物；固定套装强调所有部件一起穿，不能理解成自由搭配 |
| 动作 | match the reference video；部分加具体动作如 sneeze / walking forward | 参考只提供动作，不复制参考身份、衣着；原场景、镜头等保持 |
| 场景 | replace scene with environment in reference image | 空场景图提供环境；保留人物和原镜头，允许人物受光适应新环境 |
| 发型 | reference images 提供 shape / styling | 不复制参考人物脸、发色、服装；正背图展示同一款式、同一展示人物 |
| 发色 | change hair color to… 或 from…to… | 无参考，文字直接指定颜色；部分短指令没有逐项重述保持约束 |
| 镜头 | 明确前/后/侧、全身/半身、推进/拉远/环绕等 | 无参考，改变拍摄方式，保留人物属性、动作和环境 |

单轮各轴不同英文全文数：身份 15、服装 98、动作 268、场景 15、发型 15、发色 205、镜头 231。它们反映当前模板与参数组合，不是人工标注的独立句式数量。相同 generic prompt 必须靠参考素材区分目标，尤其身份、发型和场景；只读取文字会丢失关键监督。

例如本次 `review_6_10` 的发型 prompt 明确说明只迁移 hairstyle，不迁移 facial features、hair color 或 clothing；`review_3_09` 的整套服装则包括 one-piece garment、footwear、gloves、harness、external pockets，并强调整套一起穿。审核页展示的都是未经改写的完整中英文原文。

## 多轮历史指代

分叉并非默认接上一轮输出。4,800 次编辑从更早的历史位置取输入；英文有 1,933 次出现明确的 `video <数字>` 表达，其余还可能用语义指代。该正则计数不等价于历史指令的完整分类。

本次可直接看到：

- `review_6_09`：“Please return to video 0…”；0 表示当前链原始视频，不是全局 node 0。
- `review_1_09`：“the video that was the input to the first identity change…”；按之前任务及其输入定位。
- `review_5_09`：“the version from before the first hair color change…”；按某次编辑前的版本定位。
- `review_3_09`：“the result of edit 1…”；按轮次结果定位。

因此审核页显示本轮 source_history_index、真实 source/target 节点，并提供完整历史视频、每轮原始 prompt 和全部参考。直链与分叉各有 8 个焦点轮，分叉全部是真正从非上一轮历史位置起编辑。链中其它轮为上下文，不额外计入“80 条”。

## 使用与审核关注点

1. 图像和视频参考不可随意互换。服装/发型正背面要一起看，完整套装可能带很多参考图；此次单条最多 20 张。场景参考是空环境，不应要求复制其中人物；动作展示人物不等于目标人物。
2. 单件替换和整套替换的保持边界不同。整套任务删除旧衣物本来就是要求，不能一概按“所有其它衣物保持”审核。
3. 发色短提示、generic 动作提示与较长的保持约束并存。未来评测的提示风格应考虑这种分布，而不是全部改成详细目标 caption。这里仅报告数据现状，没有生成训练配置。
4. 参考驱动任务要分别检查“确实使用参考”和“只迁移所要求的属性”；语言写明不等于像素结果已做到。动作中的表情保持等约束，也需结合实际运动判断，不能只按文字宣布全部正确。
5. 源包原 README/SCHEMA 随包保存。SCHEMA 开头存在旧 `clothing_id/type` 说法，后文及实际节点使用 `clothing_id/slot`；展示以实际 JSON 为准。这是说明字段残留，不据此判视频错误。

已浏览 80 条 source/target 的中间帧概览及首份参考素材，用于确认展示内容：部分身份编辑取景为背面或远景（例如 review_1_01、review_1_04），强色光和逆光也会降低脸部差异的可见性；不能只凭缩略图把它们判为 no-op。完整视频和原分辨率文件均保留，样本没有因此被替换。镜头组包括环绕等明显视角变化，和之前真实 bench 以推拉为主的镜头组不同。该静帧概览不是完整运动或时序质量验收。

媒体来源的 selected-file SHA256 与源 integrity 清单核对；所有打包视频做完整解码和规格核对，PNG 原样复制。视频均保留原尺寸/帧率/帧数并去除音轨：已完成的 H.264 CRF18 浏览副本保留，其余改用原始视频码流无损封装，以减少等待。精确处理方式逐文件写入 manifest.json；源数据未改写，也未转换训练数据。画面质量、指令完成和保持性最终由用户审阅，本报告不预填评分或宣称 80 条视觉全通过。

精确抽样记录见 manifest.json、inventory.csv，全部文本统计见 prompt_statistics.json；原始样本/链 JSON、catalogs 和源说明位于 provenance/。本次没有模型推理，也没有更新先前的真实数据推理 bench。
