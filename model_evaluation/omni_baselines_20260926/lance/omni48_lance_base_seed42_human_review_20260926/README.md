# Lance Base · OmniEdit Spatial 48 人工审核包

完整解压后用 Chrome / Edge / Safari 打开 `index.html`。本包完全离线，不调用 API。

左侧是 OmniEdit 官方 source，右侧是 Lance Base 既有 seed 42 模型输出；OmniEdit Spatial 不提供 GT。两侧是已验证的 H.264/yuv420p/faststart 审阅代理，支持同步播放和拖动。

审核项初始均为空。1=通过，0=不通过，2=存疑；标注保存在浏览器 localStorage，请定期导出 CSV 或 JSON。本包不包含且不显示历史 Gemini 分数。
